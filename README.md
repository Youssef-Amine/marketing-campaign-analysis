# marketing-campaign-analysis
The aim of this project is to evaluate a fast food marketing campaign through an A/B Testing and determine which one convert the most customers.
We have a database containing the characteristics and results of 3 marketing campaigns to promote a new item in the menu of a fast-food chain. Given that there are 3 campaigns to analyze, the correct term is multivariate testing, where we compare each campaign with the others.

## Objectives

- Perform an Exploratory Data Analysis whose objective is to ensure that groups 1, 2 and 3 are well balanced on the other features
- Perform the multivariate testing
- Study confounding features, some features may affect the sales, if not controlled, they can lead to biased results, making it seem like the promotion caused the outcome when it was actually the confounder.
